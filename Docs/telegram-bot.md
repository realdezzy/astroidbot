# Telegram Bot Guide

The AstroidBot Telegram interface is designed for fast, button-first mobile trading. You can execute trades, check portfolio balances, and manage limit orders without typing complex commands.

---

## Main Menu Navigation

Send `/start` at any time to open the main dashboard menu with interactive buttons:

- **📊 Portfolio**: View total balance across all chains with breakdown by asset.
- **💼 Wallets**: Create, import, and inspect multi-chain wallets.
- **🛒 Quick Trade**: Launch interactive chain and token swap selectors.
- **📋 Limit Orders**: View, edit, or cancel open limit orders.
- **🤖 AI Agents**: Toggle AI Agent operating modes and view logs.
- **⚙️ Settings**: Adjust slippage tolerance, position sizes, and daily loss caps.

---

## Command Reference

| Command | Action |
|---|---|
| `/start` | Open main menu & inline keyboard |
| `/trade` | Start quick trade flow |
| `/portfolio` | Display multi-chain balances |
| `/wallets` | Open wallet management menu |
| `/orders` | View active limit orders |
| `/agents` | View and manage AI Agents |
| `/settings` | Open risk & slippage settings |
| `/help` | Display command list & assistance |

---

## Button-First Quick Trade Flow

1. Tap **🛒 Quick Trade**.
2. Select your chain (e.g. `🔵 Base` or `🟣 Solana`).
3. Pick your token pair.
4. Select quick amount chips (`25%`, `50%`, `75%`, `Max`).
5. Review the inline quote preview (exchange rate, DEX route, fees).
6. Tap **✅ Confirm Trade**.
