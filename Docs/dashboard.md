# Web Dashboard Guide

The Web Dashboard is your command center for portfolio analytics, strategy configuration, voice/AI trading, and token discovery.

---

## Sidebar & Navigation Overview

| Page | Icon | Purpose |
|---|---|---|
| **Dashboard** | 📊 | Overview: total multi-chain portfolio value, AI voice terminal, bot status, recent trades |
| **Portfolio** | 🥧 | Multi-chain allocation charts, cumulative PnL, volume analytics, per-wallet breakdown |
| **Token Discovery** | 🔍 | Live token screener across all chains with 24h metrics and TradingView charts |
| **Trade** | 🔄 | Execute swaps with instant DEX quote previews and optimal routing |
| **Trades** | 📋 | Full multi-chain trade history with status and filter options |
| **Limit Orders** | ⏰ | Create, monitor, and cancel automated buy/sell limit orders and stop-losses |
| **Agents** | 🤖 | Manage AI Trading Agents and their assigned quantitative strategies |
| **Yield Calculator** | 🧮 | Estimate compound strategy returns across risk profiles and timeframes |
| **Wallets** | 💼 | Create, import, reveal, and delete non-custodial wallets on any enabled chain |
| **Settings** | ⚙️ | Adjust slippage tolerance, position limits, and daily stop-loss controls |
| **Account** | 👤 | Profile management, password updates, and linked social media accounts |

---

## AI Voice & Command Terminal

Located at the top of the **Dashboard** page:
- Speak commands using the microphone icon or type natural language prompts.
- Execute instant swaps, query multi-chain balances, or create conditional limit orders hands-free.

---

## Portfolio & Analytics Hub

- **Aggregated & Per-Chain Views**: Switch between combined multi-chain portfolio values or inspect individual chain holdings.
- **TradingView Financial Charts**: High-resolution interactive charts for cumulative PnL performance and daily trading volume.
- **Theme Persistence**: Dark mode and light mode automatically synchronize with your device preferences.
